Tela Interativa de Login e Cadastro

Uma interface moderna e interativa de formulários de autenticação (Login e Cadastro), desenvolvida com foco na prática e consolidação de conceitos fundamentais do ecossistema Front-End.

Acesse o projeto online: [Clique aqui para visualizar no GitHub Pages](https://paulo2009dev.github.io/tela-interativa-login-e-cadastro-frontEnd-html-e-css-/)

Este projeto foi construído para simular uma experiência de usuário (UI/UX) agradável e intuitiva durante o fluxo de entrada e registro em uma plataforma web. 

A interface conta com formulários dedicados para:
- Login: campos para identificação (e-mail/usuário) e senha.
- Cadastro: campos estruturados para inclusão de novos dados (nome, e-mail e senha).
- Interatividade: transições visuais, foco em usabilidade e feedback claro para o usuário ao interagir com inputs e botões.

---

Tecnologias Utilizadas:

O projeto foi construído utilizando tecnologias nativas do desenvolvimento web, sem frameworks externos, garantindo um entendimento aprofundado da base:

- HTML5: Estruturação semântica de formulários, inputs, botões e organização da página.
- CSS3: Estilização visual completa, uso de alinhamentos (Flexbox/Grid), transições suaves (`transition`), pseudo-classes (`:hover`, `:focus`) e foco em hierarquia visual.

---

 Aprendizados e Habilidades Desenvolvidas:

Durante o desenvolvimento desta tela, foram trabalhadas e aprimoradas as seguintes competências:

1. Semântica e Acessibilidade: Uso correto de tags como `<form>`, `<input>`, `<label>` e `<button>`, garantindo uma boa estrutura para leitura de tela e usabilidade.
2. Estilização e Design UI: Aplicação de paleta de cores harmoniosa, espaçamentos consistentes, tipografia legível e sombreamento (`box-shadow`) para profundidade visual.
3. Microinterações: Efeitos visuais dinâmicos ao interagir com campos de texto e botões, melhorando a percepção de feedback pelo usuário.
4. Organização de Código: Separação limpa entre estrutura (`index.html`) e regras de estilo (`style.css`), facilitando a manutenção e futuras melhorias.
